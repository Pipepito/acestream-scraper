# Python dependencies for the bundled ZeroNet node (zeronet-conservancy,
# pinned by commit in docker/scripts/install-zeronet.sh).
#
# This is upstream's requirements.txt for the pinned commit with one
# deliberate change: gevent is pinned to an exact version instead of the
# `>=23.9.0` range, so a build cannot silently resolve to an untested
# release. 26.8.0 is what the pinned node was verified against.
#
# HISTORY, because the previous pin looked load-bearing and no longer is:
# the tree used to pin zeronet-conservancy v0.7.10, which deadlocks at
# startup under gevent >= 24.10 (import-time ThreadPool + LoopExit), so
# gevent was held at 23.9.1. The pinned commit here is past that problem —
# verified booting under gevent 26.8.0 — and that matters beyond tidiness:
# gevent 23.9.x publishes no aarch64 wheels for current interpreters, which
# is the whole reason the bundled node was linux/amd64 only.
#
# The DHT dependencies (fastbencode, asyncio-gevent, aio-btdht,
# aio-krpc-server) are new here: v0.7.10 predates src/DHT entirely, so the
# old dependency set had no way to express them.

# upstream pins this fork commit
