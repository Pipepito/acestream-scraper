## Failure and loading treatment

`art-absent`, `art-slow`, `art-blocked`, `art-rejected`, `art-oversized`, `art-decode-failed` and `art-changed` are selectable for Watch, player, event detail, recording parts and channel detail. Keep dimensions reserved, names and primary actions usable, and status readable without color. A changed event-artwork revision returns to explicit loading; do not auto-fetch another URL. Slow/failing generic decoration never blocks video controls or a recording action. No decorative autoplay video.

Current event fetch limits remain source-owned: explicit loading, guarded destination checks, two slots, ten-second bound, 512 KiB, supported PNG/JPEG/static WebP, maximum 4096-pixel side / four million pixels. Prototype local imagery is not evidence that arbitrary remote files pass these checks.

Concrete resource gaps: accepted non-sport programme artwork where catalogues omit it (use neutral fallback), provenance for unused supplier sports concepts, and final visual approval of the earlier generic coastline illustration. None requires inventing a media API. No additional imagery was generated in the SPORTZZ continuation.
