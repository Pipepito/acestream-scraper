# Canonical fields and editing ledger — review 03

Status: proposed design specification. Current contracts are source-checked; the displayed values in mockups are synthetic. This ledger expands critical fields and explicitly inventories [all runtime options](runtime-field-inventory.md). It does **not** claim every integration/source-specific field has final approved copy.

## Shared field rules

Each configuration field inherits: read authoritative value; distinguish unknown/loading from false/zero; retain draft on validation/server failure; disable Save when pristine/invalid/pending; Cancel restores that editor's baseline; show permission/read-only reason. Saving applies only the described endpoint scope. Preserve revision checks; stale writes require review, never silent overwrite. Display backend ranges; do not invent client defaults when unavailable.

Names, URLs, hashes, environment keys, stored enums and recipes never translate. Labels/help do. No runtime source is duplicated merely because it appears in multiple journeys.

The [current-source delta](current-source-delta.md#added-field-specification) adds six offline-cleanup/anchor settings plus availability, similar-name review and TV-link fields from develop cf952af.
