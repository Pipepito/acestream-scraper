# v2.1 upgrade notes (development)

These notes describe unreleased changes in the v2.1 working branch.

## Required: rename legacy environment variables

The one-release compatibility window in v2.0 is over. v2.1 does not read the
following names, and `ENABLE_LEGACY_ENV_ALIASES` no longer enables a fallback.
Update Compose files, container templates, `.env` files and service definitions
before starting the new version. This also applies when upgrading directly from v1.

| Removed name | Canonical name |
|---|---|
| `SCRAPER_DB_URL` | `DATABASE_URL` |
| `LEGACY_DB_URL` | `LEGACY_DATABASE_URL` |
| `ZERONET_BASE_URL` | `ZERONET_URL` |
| `CORS_ALLOW_ORIGINS` | `CORS_ORIGINS` |
| `FRONTEND_STATIC_DIR` | `FRONTEND_BUILD_PATH` |
| `ACESTREAM_ENGINE_URL` | `ACE_ENGINE_URL` |

Keep the values and persistent volume paths unchanged when renaming variables.
In particular, verify `DATABASE_URL` points at the existing database: an ignored
old name can select the default path and make the installation appear empty.
Back up the configuration volume before upgrading. Database migration support is
separate from environment aliases and remains available through `LEGACY_DATABASE_URL`.

## Extraction recipes

Sources can use HTML selectors, record-scoped regex, or JSON field paths. The
installed builder can fetch, preview and save source rules. The public tools hub
can author recipes from pasted samples without connecting to an installation.
See the [extraction builder guide](../../wiki/Extraction-Recipes.md) for examples,
limitations, troubleshooting and safe import/export.

## Source fetch protection

HTTP, IPFS gateway, ZeroNet page/iframe, nested M3U, custom recipe and EPG fetches
now connect only to DNS answers validated by the outbound guard. Redirects are
validated at every hop, including redirects to literal IP addresses. HTTPS keeps
the source hostname for certificate validation, SNI and Host headers.

`ALLOW_PRIVATE_SCRAPE_TARGETS=true` remains the default for existing LAN setups.
Set it to `false` for an exposed installation; configured ZeroNet/IPFS gateway
hosts remain exempt. IPv4/IPv6 cloud metadata addresses are always blocked.
Source fetches do not inherit `HTTP_PROXY`/`HTTPS_PROXY` environment proxies, which
could otherwise resolve destinations outside the guard. This does not change
container network routing such as WARP. Remote-player/media-server LAN clients
retain their separate destination policy.

## Advanced stream statistics (#122)

Manual, bulk and scheduled stream checks retain the latest valid peer count and
P2P download/upload rates with their observation time. Acestream Channels shows
these alongside independently measured media bitrate on desktop and phone views.
Skipped checks preserve observations; missing values remain unknown. These short
samples do not imply verified signal or sustained throughput.
See [stream statistics](../../wiki/Stream-Statistics.md) for collection steps,
units and limitations. History, automatic playlist thresholds and loop detection
remain outside this version.
