## Corrections found during validation

- Health and OpenAPI metadata still hard-coded `2.0.0`, and the image omitted
  the release file. Both now read `version.txt`, which is copied into the image;
  checkout and flattened-image lookup have regression coverage.
- Two mobile route fixtures still matched the pre-#229 channel URL. They now
  mock the canonical trailing-slash URL.
- Overview treated a bundled engine as configured after the saved playback URL
  was cleared. It now follows the saved URL, with regression coverage.
- Explicitly disabled WARP produced an error log for its expected absent daemon.
  Only that precise status-probe case is downgraded; real errors remain errors.
- The packaged FFmpeg intentionally lacks media-generation and frame-hash tools.
  Remux tests now accept a separate fixture tool while still exercising the
  shipped remux binary. The disposable image test environment also needs Git,
  Node, `fs-extra`, and an unprivileged test user for repository-tooling tests.
- Scrape status is recorded before channel ingestion completes. The browser
  helper now waits for the manual job to finish before asserting stored counts.
- EPG polling can coincide with Uvicorn's keep-alive socket expiry. Its read-only
  GET permits one transport reset retry; HTTP failures and repeated resets still
  fail. The health watcher also observes rejected completion without producing
  a second unhandled rejection.
- Strict browser monitoring reads the scraper capture log. Expected errors for
  deliberately unreachable sources and a password-less VLC are declared only
  by their respective tests, and retained in the attached error evidence.
- The reorder journey seeds its required inventory instead of skipping.
- The notification journey waits for the shared probe queue's current background
  probe and cooldown before asserting the exact manual-check webhook.

## Scope limits

Docker runs use native ARM64 and emulated amd64 on this computer. ARMv7
build/installation contracts do not replace runtime testing on physical ARMv7.
The bundled engine's optional ARM WebRTC initialization emits upstream library
diagnostics separately from application logs; HTTP playback is tested directly.
Public source availability is a dated observation, not a permanent guarantee.

Raw logs, databases, browser traces and reports remain local runtime artifacts.
Release acceptance still requires current CI for the actual PR heads and the
eventual develop/main commits. Follow [v2.2 readiness](v2.2-release-readiness.md).
