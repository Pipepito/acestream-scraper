  `gh pr view 207 --json state,mergeable,mergeStateStatus,statusCheckRollup,updatedAt,url`.
- [ ] Review the [release notes](v2.2-release-notes.md), Alembic upgrade path and
  final local/CI evidence. Do not reuse an earlier SHA's green result.
- [ ] Obtain maintainer release authorization, then follow the
  [Jenkins runbook](../ops/jenkins-ci.md): merge, validate the exact main commit,
  manual dry run, version publication, canary, and separate latest promotion.
- [ ] Verify released behavior before closing issues marked awaiting release.
  Git tags and GitHub release notes remain manual.
