## Remaining signals and boundaries

Vite still reports two existing chunks above 500 kB: HLS approximately 575 kB
and MUI DataGrid approximately 676 kB. No threshold was raised and no output was
hidden. Bundle reduction needs a separate loading/performance change and browser
verification; passing TypeScript/lint does not resolve this advisory.

The responsive and monitor runners inherited conflicting NO_COLOR/FORCE_COLOR variables and
reported Node's color-setting warning. The subsequent strict Firefox runs use
consistent color settings. This is runner environment noise, not an application
deprecation.

The initial backend attempts exposed sandbox socket restrictions, missing host
media tools and resource leaks. A later run passed 1,926 tests and failed
one on external TLS teardown; its unintended public fetch was replaced and the
45-test scraper suite passed; only the final prepared Linux result counts as
full backend evidence. The initial extra browser run also exposed missing seeded
state and assumptions about a configured engine; those checks were repaired and
rerun. Logs, databases, traces and screenshots remain untracked.

Multiarchitecture image rebuilds, external public-peer playback and physical ARMv7
runtime checks were not repeated here. No Jenkins configuration, release job,
image publication, tag promotion or protected-branch merge was performed.
